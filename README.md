# local-agent 0.1

Локальный ИИ-агент для терминала в стиле Claude Code: работает на **ваших** моделях
через [llama.cpp](https://github.com/ggml-org/llama.cpp), без облака и без API-ключей.
Читает и правит файлы, ищет по коду, запускает команды и умеет откатывать свои изменения.

```
  _                _     _                _
 | |   ___   ___  | |   / \   __ _  ___ _ __ | |_
 | |  / _ \ / __| | |  / _ \ / _` |/ _ \ '_ \| __|
 | |_| (_) | (__  | | / ___ \ (_| |  __/ | | | |_
 |_(_)\___/ \___| |_|/_/   \_\__, |\___|_| |_|\__|
                             |___/
```

> **Статус: 0.1 — ранняя версия.** Основной сценарий работает, но проект молодой:
> см. [Известные ограничения](#известные-ограничения) перед тем, как доверять агенту
> важные файлы.

## Что умеет

**Агент в терминале** — 10 инструментов, как у «настоящих» агентов:

| Инструмент | Назначение |
|---|---|
| `read_file` | чтение файла с постраничным выводом (`offset` / `limit`) |
| `write_file` | создать файл или перезаписать целиком |
| `edit_file` | точная замена фрагмента; `old_string` должен быть уникален |
| `apply_patch` | unified diff, можно несколько файлов сразу |
| `list_dir` | содержимое папки с размерами |
| `glob` | поиск файлов по шаблону (`**/*.py`) |
| `grep` | поиск регулярки по содержимому (`include` — маска файлов) |
| `run_shell` | команда оболочки в рабочей папке (по умолчанию 180 с) |
| `web_fetch` | скачать страницу и вернуть текст |
| `todo_write` | список задач со статусами |

**Откат правок.** Каждое изменение файла попадает в журнал (`undo/journal.jsonl`)
вместе с копией исходника. Команда `/undo` возвращает всё, что агент сделал за
последний ход. Кнопка «как было» — это принципиально, а не приятный бонус.

**Подтверждения.** По умолчанию каждая запись в файл и каждая команда оболочки
требует ответа: `y` — разрешить, `a` — разрешить и больше не спрашивать, `n` — нет.

**Загрузка моделей.** Вставляете ссылку на Hugging Face — прямую на `.gguf` или
страницу репозитория: программа покажет список доступных квантов и отметит `Q4_K_M`.
Загрузка идёт с прогресс-баром, обрывается и продолжается с места разрыва
(HTTP Range + проверка SHA-256).

**llama.cpp ставится сам.** Программа находит свежую сборку под вашу ОС
(Windows x64/arm64, macOS Intel/Apple Silicon, Linux x64/arm64) и распаковывает её.
Если что-то пошло не так — предложит ручную установку.

**Открытый API.** С флагом `--server-only` поднимается OpenAI-совместимый
`/v1/chat/completions`, к которому можно подключить любые другие клиенты.

## Установка: одна команда

Нужен Python **3.8+**. Больше ничего ставить вручную не требуется.

```bash
python local_agent.py
```

Первый запуск один раз спрашивает и делает всё сам:

1. **Папка программы.** Удобно, когда всё (модели, бинарники, логи, venv) лежит
   в одном месте — выбрать можно свой путь, выбор запоминается.
2. **Структура каталогов** внутри неё: `llama.cpp/`, `models/`, `undo/`, `logs/`,
   `workspace/`, `venv/`.
3. **Зависимости** (необязательные: `psutil`, `certifi`) — в отдельный `venv`,
   чтобы не трогать системный Python.
4. **Команда `stai`** — после этого запуск из любого каталога:

```bash
stai
```

Дальше `stai` работает молча: никаких мастеров, никаких переустановок.

Где программа хранит данные по умолчанию:

| ОС | Путь |
|---|---|
| Windows | `%APPDATA%\local-agent` |
| macOS | `~/Library/Application Support/local-agent` |
| Linux | `~/.local/share/local-agent` |

Поменять папку можно в любой момент: `stai --set-home` (или разово `--home ПУТЬ`),
а также переменной окружения `LOCAL_AGENT_HOME`. Выбор хранится в
`.local-agent-home.json` рядом со скриптом, поэтому перенос всего каталога
на другую машину ничего не ломает — кроме этой строчки.

## Первый сценарий

```bash
stai --model https://huggingface.co/bartowski/Qwen2.5-Coder-7B-Instruct-GGUF
```

Программа спросит, какой квант качать, скачает `llama.cpp`, запустит сервер и
откроет чат. Дальше просто пишете задачу:

## Флаги

| Флаг | Что делает |
|---|---|
| `--model URL\|путь` | модель: ссылка Hugging Face или локальный `.gguf` |
| `--cwd ПАПКА` | рабочая папка агента (по умолчанию текущая) |
| `--yes` | не спрашивать подтверждений правок и команд |
| `--ctx N` | размер контекста (по умолчанию из модели) |
| `--gpu-layers N` | слоёв на GPU; `0` — только CPU, `-1` — авто |
| `--threads N` | потоков CPU |
| `--port N` | порт llama-server (по умолчанию свободный) |
| `--token TOKEN` | HF-токен для gated-моделей (или `HF_TOKEN`) |
| `--temperature F` | температура генерации (0.2) |
| `--server-only` | поднять только API, без чата |
| `--home ПАПКА` | указать папку программы и запомнить |
| `--set-home` | заново выбрать папку и выполнить настройку |
| `--no-bootstrap` | ничего не устанавливать и не прописывать |
| `--no-mascot` / `--no-color` | выключить маскота / цвета |

## Команды в чате

```
/help      /tools     /undo      /history   /files
/cwd ПУТЬ  /yes       /ask       /new       /clear
/stats     /server    /mascot    /exit
```

Многострочный ввод: строка, заканчивающаяся на `\`, или тройные кавычки.
Ввод, начинающийся с `!`, выполняется в оболочке напрямую, без модели.

## Структура проекта

```
local_agent.py     — вся программа (один файл, стандартная библиотека)
scripts/stai.py    — обёртка, которую запускает команда stai
```

Второй файл **обязателен**: без него команда `stai` не создаётся. Копия этого
файла кладётся и в папку программы — чтобы `stai` не зависел от того, где лежит
исходник.

## Известные ограничения

Честный список того, что не работает или работает не идеально в 0.1:

- **`stai` на Windows — это `.cmd`-шим**, а не alias оболочки. Он ставится в
  `%LOCALAPPDATA%\Microsoft\WindowsApps` (эта папка уже есть в `PATH`) либо,
  если запись туда запрещена, — в собственную папку плюс `PATH` пользователя.
  Обновлённый `PATH` подхватывается **только новым окном терминала**.
- **Запрет скриптов PowerShell `Restricted`** (как в свежей Windows по умолчанию)
  ломает резервный вариант через профиль. Шим в `PATH` при этом продолжает работать.
- **Генерация без проверки.** Успешность операции оценивает модель, а не тесты.
  Цикл «правка → тест → правка» работает, только если модель сама запустит тесты.
- **Контекст обрезается** до последних 60 сообщений — длинные сессии «забывают» начало.
- **Автотестов нет.** Проверялись только ручные сценарии, поэтому граничным
  случаям веры меньше, чем хотелось бы.
- **Автовыбор числа слоёв на GPU** пока грубый (`-ngl` по умолчанию `-1`, то есть
  «как решит llama.cpp»). Детектор железа остался в планах.
- **Модель должна уметь вызывать инструменты.** Мелкие модели (12B и меньше)
  часто ломают формат `<tool_call>`; парсер умеет восстанавливаться, но не всегда.

## Безопасность

Агент **полноценно выполняет команды оболочки** в рабочей папке от вашего имени.
Это по замыслу, но означает: запускайте его в папке, которую не боитесь испортить,
и не отключайте подтверждения (`--yes`) на важных проектах.

- правки файлов после агента видно в `undo/journal.jsonl`, откат — `/undo`;
- не запускайте программу от имени администратора;
- не вставляйте в чат секреты — они уйдут модели в контекст.
