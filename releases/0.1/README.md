# local-agent 0.1 — сборка «всё в одном файле»

Один файл, никаких зависимостей рядом. Скопируйте `local_agent.py` куда угодно
и запустите.

```bash
python local_agent.py
```

Нужен Python **3.8+** и ничего больше: даже `scripts/stai.py` не требуется —
launcher'ом для команды `stai` становится копия этого же файла.

## Как это устроено

При первом запуске программа спросит одну папку, развернёт в ней всё нужное
(`llama.cpp/`, `models/`, `undo/`, `logs/`, `workspace/`, при необходимости `venv/`),
подтянет необязательные пакеты и пропишет команду `stai` в `PATH`.
Дальше запуск из любого каталога:

```bash
stai
```

## Отличия от полной версии

| | Полная версия | Этот файл |
|---|---|---|
| Файлов | `local_agent.py` + `scripts/stai.py` | один `local_agent.py` |
| Launcher `stai` | шаблон из `scripts/stai.py` | копия самого файла |
| Поведение | одинаковое | одинаковое |

Единственное практическое следствие: если вы удалите оба файла — и исходник,
и копию в папке программы, — команда `stai` перестанет находить код.
В полной версии так же.

## Полезные флаги

```bash
python local_agent.py --set-home      # заново выбрать папку программы
python local_agent.py --server-only   # поднять только API llama-server
python local_agent.py --no-bootstrap  # ничего не ставить и не прописывать
```
